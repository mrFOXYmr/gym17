PYTHON

Конвертация в Python

# Десятичное -> другие системы
>>> bin(65)        # '0b1000001'
>>> oct(65)        # '0o101'
>>> hex(65)        # '0x41'

# Обратно в десятичное
>>> int('0b1000001', 2)   # 65
>>> int('0x41', 16)       # 65
>>> int('41', 16)         # 65 (без префикса)

# format() — без префиксов
>>> format(65, 'b')   # '1000001'
>>> format(65, 'x')   # '41'
>>> format(65, '08b') # '01000001' (дополненный)

4 функции — рефлекс

  • bin() → двоичная
  • oct() → восьмеричная
  • hex() → шестнадцатеричная
  • int(x, base) → обратно в десятичное
int() принимает второй аргумент — основание системы. Без него строка воспринимается как десятичная.
Трюк format(65, '08b') — удобен для получения ровно 8 бит (одного байта). Пригодится в задачах с бинарными строками.

ord(chr) — взаимнообратные

ord(chr(x)) == x всегда.
chr(ord(c)) == c всегда.

Полезно для перевода строки в список кодов и обратно: [ord(c) for c in s].
Подводный камень ord() принимает только 1 символ. ord('ab') → TypeError. Для строки нужен list comprehension.
Русские буквы ord('ф') = 1092 — это уже Unicode (код-пункт U+0444). ASCII охватывает только 0-127.

ord(chr) — взаимнообратные функции. ord(chr(x)) всегда == x.

BASE64

Base64 — что это и зачем

Кодирует любые бинарные данные в печатные ASCII-символы. Алфавит: A-Z, a-z, 0-9, +, / (64 символа). Дополняется символом '='.

Где используется

  • Email (MIME)
  • Data: URLs в HTML
  • JWT токены
  • Картинки в CSS (background: url(data:image/png;base64,...))
  • CTF флаги (очень часто)
Зачем: не все байты можно безопасно передать как текст (например, байт 0x00 ломает протоколы). Base64 переводит любые байты в "безопасные" ASCII.

Примеры

'CTF'  -->  Q1RG
'flag' -->  ZmxhZw==

Длина и распознавание

Длина base64 = ~4/3 от исходных данных (на 33% больше).

Regex для base64:

^[A-Za-z0-9+/]*={0,2}$

Объяснить проблему. Не все байты можно безопасно передать как текст. Например, байт 0x00 (null) ломает многие протоколы (C-строки). Base64 решает это — переводит любые байты в "безопасные" печатные ASCII.

Алфавит

64 символа: A-Z (26) + a-z (26) + 0-9 (10) + '+' и '/' = 64. Padding '='.

Размер

Типичная длина base64 = ~4/3 от исходных данных (то есть на 33% больше). Это плата за безопасность.

Вопрос классу

Как выглядит base64 с точки зрения регулярок? Ответ: ^[A-Za-z0-9+/]*={0,2}$ — это пригодится при анализе подозрительных строк.

BASE64 · HOW

Как работает Base64 — визуально

Кодирование 'Man' → 'TWFu'. Берём 3 байта (24 бита), разбиваем на 4 группы по 6 бит.

Шаг 1. Байты 'M' 'a' 'n' → 77 97 110
Шаг 2. В двоичном: 01001101 01100001 01101110 (24 бита)
Шаг 3. Разбиваем на 4 группы по 6 бит:
010011 · 010110 · 000101 · 101110
Шаг 4. Каждая группа → индекс: 19, 22, 5, 46
Шаг 5. По таблице: 19='T', 22='W', 5='F', 46='u'
Шаг 6. Результат: TWFu
Если длина не кратна 3 — добавляется padding '='. Поэтому в конце base64 часто 1 или 2 знака '='.

Алфавит (первые 16)

0=A · 1=B · 2=C · 3=D
4=E · 5=F · 6=G · 7=H
8=I · 9=J · 10=K · 11=L
12=M · 13=N · 14=O · 15=P
16=Q · 17=R · 18=S · 19=T
20=U · 21=V · 22=W · 23=X
24=Y · 25=Z · 26=a · 27=b
28=c · 29=d · 30=e · 31=f
... и так до 63='/'

Важно объяснить идею: берём 3 байта (24 бита), разбиваем на 4 группы по 6 бит. Каждая 6-битная группа = число 0-63 = индекс в алфавите из 64 символов. Поэтому и называется base64.

Padding

Если длина не кратна 3 — добавляется padding '='. Если 1 байт остался → '=='. Если 2 байта осталиcь → '='. Если кратно 3 → ничего.

Пройти по схеме медленно

Можно вместе посчитать: 010011 в десятичной = 16+2+1 = 19. По таблице 19=T. 010110 = 16+4+2 = 22 → W. И т.д.

Base64 в Python

import base64

# Кодирование
>>> base64.b64encode(b'CTF')
# b'Q1RG'

# Декодирование
>>> base64.b64decode('Q1RG')
# b'CTF'

# ВАЖНО: работает с bytes, не str!
>>> base64.b64encode('CTF')       # ОШИБКА
# TypeError: a bytes-like object is required

# Поэтому обычно так:
>>> s = 'CTF'
>>> b64 = base64.b64encode(s.encode()).decode()
>>> b64
# 'Q1RG'

# И обратно:
>>> decoded = base64.b64decode(b64).decode()
>>> decoded
# 'CTF'

Главный подводный камень

base64 работает с bytes, не str!

Если у вас строка — сначала .encode(), потом b64encode(). Результат — bytes, поэтому .decode() обратно в str.

str vs bytes

str — текст (Unicode)
bytes — байты (числа 0-255)

base64 — про байты. b'CTF' ≠ 'CTF'.

Это самая частая ошибка у школьников. Пройти по строкам с .encode() и .decode() медленно, по одной строке.

Разница str/bytes

str — это текст (Unicode). bytes — это байты (числа 0-255). base64 — про байты. 'CTF' (str) ≠ b'CTF' (bytes).

Паттерн

Стандартный цикл: str → .encode() → bytes → b64encode() → bytes → .decode() → str. Запомнить эту цепочку.

Вопрос классу

Что будет если применить b64encode к уже закодированной строке? Ответ: ничего страшного, получится base64 от base64 (часто встречается в CTF как многослойная задача).

Простые правила
  • Если видите только [A-Z2-7=] — это Base32.
  • Если только [0-9a-f] — это hex.
  • Если смесь регистров + цифры + иногда +/= — это Base64.
  • Если в base64-подобной строке есть '-' или '_' — это URL-safe Base64.

Разбираем задачу вместе

Задача. Дано: 6374667b6578616d706c657d. Найти флаг.

Пошаговый разбор

  1. Видим только символы 0-9a-f → это hex
  2. Каждые 2 hex-символа = 1 байт. 12 пар = 12 байт
  3. Переводим в символы по таблице ASCII: 63='c', 74='t', 66='f', 7b='{', 65='e'...
  4. Собираем строку: ctf{example}
Стратегия: всегда сначала определяем алфавит, потом подбираем кодировку.

Решение в Python

# Способ 1: binascii

ROT13

ROT13 и ROT-N

ROT13 — сдвиг каждой буквы на 13 позиций в алфавите. Особенность: применён дважды — даёт исходный текст (потому что 26 = 2 × 13). ROT-N — обобщение (сдвиг на N).

Визуальный пример

'hello'  --ROT13-->  'uryyb'
'uryyb'  --ROT13-->  'hello'

Исторический факт

ROT13 использовался в Usenet (1980-е) для скрытия спойлеров к фильмам и шуток.

ROT13 технически — шифр Цезаря со сдвигом 13. Но поскольку ключ всегда 13 и всем известен — на практике работает как кодировка. В CTF относят к "псевдошифрам".

Почему 13?

26 букв в алфавите, 26 = 2 × 13. Поэтому ROT13(ROT13(s)) = s. Симметричность — только при N=13.

Для русского (33 буквы) симметричного N нет. ROT-N для русского — не симметричен.

Объяснить идею сдвига: A→N, B→O, ..., M→Z, N→A (зацикливание).

ROT13 = ROT-N с N=13

Симметричность (encode = decode) — это удобно, но встречается только при N=13 (для алфавита длиной 26).

Для других N

encode и decode разные. Например, ROT5: 'hello' → 'mjqqt', обратно нужен ROT21.

ROT для русского

ROT33 (33 буквы), но не симметричен. В CTF встречается редко.

# Способ 2: maketrans + translate (любой ROT-N)
import string
def rot_n(s, n):
    alphabet = string.ascii_lowercase
    shifted = alphabet[n:] + alphabet[:n]
    table = str.maketrans(
      alphabet + alphabet.upper(),
      shifted + shifted.upper())
    return s.translate(table)

>>> rot_n('hello', 13)  # 'uryyb'
>>> rot_n('hello', 5)   # 'mjqqt'  (ROT5)

# Брутфорс всех 25 ROT-N:
for n in range(1, 26):
    print(n, rot_n('uryyb', n))

UTF-8 — как кодируется

UTF-8 — кодировка переменной длины. Один символ может занимать 1, 2, 3 или 4 байта.

1 байт (ASCII):    0xxxxxxx                             (0-127)
2 байта:           110xxxxx 10xxxxxx                  (128-2047)
3 байта:           1110xxxx 10xxxxxx 10xxxxxx        (2048-65535)
4 байта:           11110xxx 10xxxxxx 10xxxxxx 10xxxxxx  (65536+)

😀U+1F600f0 9f 98 80 (4 байта)
Smart design fact: Все ASCII символы (0-127) в UTF-8 = 1 байт и идентичны ASCII. Поэтому UTF-8 обратно совместим с ASCII.

Prefix bits

10xxxxxx — continuation byte (продолжение).

110xxxxx — начало 2-байтной последовательности.

Это позволяет синхронизироваться в любой позиции потока байтов.

Объяснить, почему префиксные биты важны.

10xxxxxx — маркер continuation byte

Если видим байт 110xxxxx — знаем, что это начало 2-байтной последовательности. Это позволяет синхронизироваться в любой позиции потока байтов (не нужно искать начало).

Обратная совместимость

ASCII символы (0-127) в UTF-8 = 1 байт и идентичны ASCII. Поэтому любой ASCII-текст — это валидный UTF-8.

В CTF

Иногда данные хранятся в UTF-16 (каждый символ 2 или 4 байта, много нулевых байтов) — узнаём по pattern 0xXX 0x00.

encode / decode — основа

Все строки в Python 3 — Unicode. Чтобы получить байты — encode(). Чтобы из байтов сделать строку — decode().

ord() даёт код-пункт (Unicode номер), а не байты. 'a'=1 байт, 'ф'=2 байта, '😀'=4 байта — но len()==1 для всех.

Подводные камни

Составные эмодзи (🇷🇺) и комбинирующие диакритики — где 1 "символ" = несколько code-пунктов.

Это важный слайд для понимания различий строк и байтов в Python 3.

Все строки — Unicode

Чтобы получить байты — encode(). Чтобы из байтов сделать строку — decode().

Brainfuck — что это

Эзотерический язык программирования, придуман в 1993 году (Urban Müller). Всего 8 команд, но Тьюринг-полный. В CTF — частая misc-головоломка.

Mental model

Лента на 30 000 ячеек, указатель, циклы [ ] повторяются пока ячейка не 0.

Все остальные символы (пробелы, переводы строк) — игнорируются.

Простой пример: 65 плюсов и точка = вывод 'A'. Циклы позволяют умножать: 5 +, потом [>+++++<-] = 5 × 5 = 25 в следующей ячейке.

В CTF

Обычно программы небольшие — выводят флаг или закодированную строку (которую надо декодировать дальше).

Объяснить концепцию: язык издевается над программистом (отсюда название). Но в нём можно написать любую программу — он Тьюринг-полный.

Brainfuck — интерпретатор и тулзы

Python интерпретатор (~20 строк)

def brainfuck(code, input_data=''):
    tape = [0] * 30000
    ptr = pc = 0
    output = []
    # Precompute jump positions
    jumps, stack = {}, []
    for i, c in enumerate(code):
        if c == '[': stack.append(i)
        elif c == ']':
            j = stack.pop()
            jumps[i] = j; jumps[j] = i
    while pc < len(code):
        c = code[pc]
        if   c == '>': ptr += 1
        elif c == '<': ptr -= 1
        elif c == '+': tape[ptr] = (tape[ptr]+1) % 256
        elif c == '-': tape[ptr] = (tape[ptr]-1) % 256
        elif c == '.': output.append(chr(tape[ptr]))
        elif c == ',':
            tape[ptr] = ord(input_data[0]) if input_data else 0
            input_data = input_data[1:]
        elif c == '[' and tape[ptr] == 0: pc = jumps[pc]
        elif c == ']' and tape[ptr] != 0: pc = jumps[pc]
        pc += 1
    return ''.join(output)

Решение 8 · ctf{master_combo}

hex(BF(b64(URL)))

import base64
from urllib.parse import unquote

# Шаг 1: hex -> Brainfuck

# Шаг 2: запускаем Brainfuck

# Y3RmJTdCbWFzdGVyX2NvbWJvJTdE

# Шаг 3: base64 decode
url_str = base64.b64decode(b64_str).decode()
# ctf%7Bmaster_combo%7D

# Шаг 4: URL decode
flag = unquote(url_str)
print(flag)
# ctf{master_combo}
