# Домашнее задание 3 — Linux и математика Python

## Часть A. Права и chmod
1. Расшифруй `rw-`, `r-x`, `r--`, `--x`, `---` в числа.
2. Что даст `chmod 640 file`? `chmod 774 file`? Запиши права каждой группы.
3. **Флаг-задача (правa):** файл должен быть:
   - readable владельцем;
   - writable владельцем;
   - executable владельцем и группой;
   - остальные без доступа.
   Подбери восьмеричную маску. 
   > Флаг: `LNA{<маска>}` (например `LNA{711}`).

## Часть C. iptables (реальный сценарий)
Опиши, чем отличается:
```
iptables -A INPUT -p udp --dport 53 -j DROP
iptables -A INPUT -p udp --sport 53 -j DROP
```
Сформулируй правило: «разрешить входящие HTTP-запросы только с подсети 10.0.0.0/8, всё остальное дропать». Запиши оба правила (ACCEPT + DROP).

## Часть D. Математика, как в НТО (без модуля — вручную)
1. НОД: реализуй алгоритм Евклида циклом (без `math`).
2. **НОК** через `a*b//gcd`.
3. **Сумма цифр** числа до 10¹⁸.
4. **Делимость.** Количество чётных чисел от 1 до n.
5. **Простота.** Для `n` до 10⁹ посчитай всех простых делителей (перебор до √n).

## Часть E. Флаг-задача «Код два сейфа»
Нужно подобрать 3 цифры `abc` такие, что `НОД(a·b, c·100 + a) == 7` и `НОД(a + b + c, 2026) == 1`, где `a,b,c` — цифры и сумма цифр минимальна.
Перебором (~900 вариантов) найди минимальный ответ.
> Флаг: `CFR{<abc>}` — три цифры подряд.
