## Часть B. Пассивный анализ (флаг в файле)

1. Построй функцию поиска флага в байтах:
```python
def find_flag(data: bytes, needle: bytes) -> list[int]:
    idx, res = 0, []
    while True:
        i = data.find(needle, idx)
        if i == -1: break
        res.append(i); idx = i + 1
    return res
```
