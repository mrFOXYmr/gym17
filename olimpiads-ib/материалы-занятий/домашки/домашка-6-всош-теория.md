## Часть B. Многослойное декодирование (флаг-задача)
Дан шифротекст, закодированный несколько раз (смешаны Base64 и Base32):
```
S05DVUdWS1NJVlBVR1NLUUpCQ1ZFWFpVR0k9PT09PT0=
```
1. Это Base64 — декодируй один раз. Получится другая строка.
2. Определи, это снова Base64 или Base32 (по алфавиту), и декодируй дальше.
3. Повторяй, пока не прочитается осмысленное сообщение.
Подсказка — универсальная функция-«раскрутка», которая пробует оба варианта и останавливается по `try/except`:
```python
import base64

def unwrap(s: str) -> str:
    while True:
        for fn in (base64.b64decode, base64.b32decode):
            try:
                s = fn(s).decode(); break
            except Exception:
                continue
        else:
            break
    return s
```
