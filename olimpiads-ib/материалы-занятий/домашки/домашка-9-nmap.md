## Часть B. Чтение результата (реальный скан)
Дан вывод (учебная VM). Открой его, сопоставь порты и сервисы:
```
PORT     STATE SERVICE  VERSION
22/tcp   open  ssh      OpenSSH 8.2 
80/tcp   open  http     nginx 1.18.0
3000/tcp open  http     Node.js Express
3306/tcp open  mysql    MySQL 8.0.29
```
1. Какой сервис с наибольшей вероятностью «веб-приложение» (80 vs 3000)? Почему?
2. Что дальше делаешь с портом 3306? С портом 3000?
3. Какая команда дала бы стройки и более полные данные (найди и запиши одну команду, которая покрывает `-sC -sV`)?
