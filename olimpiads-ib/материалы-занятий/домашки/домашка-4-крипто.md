# Домашнее задание 4 — Классическая криптография

## Часть A. Шифр перестановки
Расшифруй блоки «312»-правилом слово `ПОЧТАЛЬОН` (блоки 3). Запиши ход для каждого блока.
> Флаг1: `CRP{<расшифровка>}` в верхнем регистре.

## Часть B. Цезарь/ROT на Python
Напиши `caesar(s, shift)` для кириллицы (перенос по 32 буквам). Примени на тест:
`СДВИНУТЬ НА 3` → зашифруй сдвиг +3, расшифруй обратно.
1. Проверь циклический перенос: буква `Э` со сдвигом `+3` → какая?

## Часть C. Цезарь и вскрытие (мини-CTF)
1. Напиши функцию для кириллицы (32 буквы, без `Ё`) и расшифруй шифротекст, полученный сдвигом `+3`:
   `ТГУСОЯ`
   (сдвиг `−3` вернёт осмысленное слово).
2. Частотный анализ: построй таблицу частот для короткого русского текста (`Counter`) и определи самую частую букву. Объясни, почему с увеличением длины текста результат надёжнее.
> Флаг: `CRP{<расшифрованное из п.1 слово>}` в верхнем регистре.

## Часть D. Решётка Кардано (Верченко)
Прочитай условие «Решётки Кардано» в `Верченко/2024-25/11-отбор_задания-ответы.pdf`. Опиши алгоритм (маска + 4 поворота на 90°) и дореши пример из условия. Запиши прочитанную строку.

## Часть E. Контрольная сумма (XOR)
1. Построй XOR-сумму всех байт строки `NTO`.
2. Что изменится, если заменить один символ? Проверь.
3. Реши задачу Верченко «Контрольная сумма» из архива (11 класс).
