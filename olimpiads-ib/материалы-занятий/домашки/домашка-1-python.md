## Флаг-задача. «Шифр-обфускатор» (мини-CTF)
Реализуй функцию `xor(data, key)`, которая пословно xor-ит байты с коротким ключом.
Формат обмена — hex. Сверь себя на контрольном примере.

```python
def xor(data, key: bytes) -> bytes:
    return bytes(a ^ b for a, b in zip(data, key * len(data)))

payload = bytes.fromhex("070e0005")            # зашифрованные данные
print(xor(payload, b"AB").hex())               # расшифровка ключом "AB"
```

Реши цепочку: `bytes.fromhex("070e0005")` зашифрована словом из 4 букв ключом `AB`.
1. Расшифруй её ключом `AB` — прочитается слово.
2. Перезашифруй результат тем же ключом — должен снова получиться исходный `070e0005`.
> Флаг = расшифрованное слово в верхнем регистре, обёрнутое в `FLAG{...}`.
> Пример формата: `FLAG{TEXT}`.
