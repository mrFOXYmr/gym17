## Часть C. PPC (Python, обработка лога)
**Флаг-задача.** Лог содержит строки вида:
```
192.168.1.10 GET /login
8.8.8.8     GET /home
192.168.1.10 GET /login
10.0.0.2    POST /login
192.168.1.10 GET /flag
172.16.0.5  GET /login
```
Найди IP с максимальным числом запросов и IP публичного диапазона (не `10.`/`172.16.`/`192.168.`).
```python
from collections import Counter
pending = """..."""   # скопируй лог выше
ips = [line.split()[0] for line in pending.splitlines()]
print(Counter(ips).most_common(3))
```
1. Самый частый IP в логе;
2. Единственный «публичный» IP.
> Флаг: `PPC{<самый-частый-IP>-<публичный-IP>}` (например `PPC{192.168.1.10-8.8.8.8}`).
