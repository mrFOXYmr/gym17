# Домашнее задание 5 — Алгоритмы (НТО Этап I)

## Часть A. Перебор
1. Все делители числа `n` (возрастанием) — за O(√n), а не O(n).
2. Сумма делителей числа `n`.
3. Наименьший делитель > 1 составного числа.
4. **Проверка**: посчитай количество натуральных чисел ≤ 10⁶, у которых ровно 3 делителя (это квадраты простых). Выведи это количество.

## Часть B. Конструктивное построение
Задача «Пробежка в шестиугольном парке» (НТО `infbez-отбор-тур1`): вход `k` (кратно 100), вывести маршрут длины `k/100` символов, построив повторяющийся паттерн. Объясни, почему паттерн `ABABA` (длина 5) корректен, и как получить остаток через `%`.

## Часть C. Битовая арифметика (мини-CTF)
Реализуй без `bin()`/`format()`:
```python
def count_bits(n): ...   # число единичных битов
def is_power_of_two(n): ...  # через n & (n-1)
def lowest_bit(n): ...   # наименьший установленный бит: n & -n
```
Примени на `n = 0b101101` (десятичное 45):
- сколько единичных битов;
- является ли степенью двойки;
- чему равен `n & -n`.
> Флаг: `ALG{<кол-во единиц>-<n&-n>}` — для `n=45`: `ALG{4-1}`.

## Часть D. Жадность и оптимизация
«Оптимизация числа» (НТО): обмен соседних цифр за |a−b|. Для `4519 → 9541` посчитай суммарное время по шагам и запиши идею алгоритма. Реши на ещё одном примере из архива.

## Часть E. Оценка сложности
Оцени O(...):
- перебор делителей до √n;
- `sorted()` списка из n элементов (`list.sort()`);
- проверка простоты перебором до √n;
- наивный перебор делителей до n.
Сравни, какой из двух вариантов поиска делителей быстрее и во сколько раз для `n = 10⁸`.
