## Часть B. XOR-флаг (односимвольный ключ)
Шифротекст получен XOR-ом осмысленной фразы одним символом (ключ 0..255).
```python
ct = bytes.fromhex("07141c11751b1a02")
for k in range(256):
    d = bytes(c ^ k for c in ct)
    if d.isascii() and all(32 <= x < 127 for x in d):
        print(k, d)   # ищи читаемую фразу
```
Подбери ключ, при котором расшифровка — осмысленная фраза.
> Флаг: `CRYPTO{<расшифрованная-фраза-в-верхнем-регистре-с-_>-вместо-пробелов}` (например `CRYPTO{GO_FAST}`).
