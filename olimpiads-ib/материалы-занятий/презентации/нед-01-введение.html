    Ключевой термин — ФЛАГ

  • CTF = Capture The Flag: за решение таска получают строку-«флаг».
  • Флаг = скомпрометированные данные, пароль, секрет, ответ задачи.
  • Формат всегда задан: vsosh{...}, NTO{...}, FLAG{...}.
  • Важно: сдать ровно строку флага — лишний пробел или регистр = 0 баллов.

    • Структура CTF-олимпиады (тур1 Иннополис)

  • Задают категории: CRYPTO, FORENSIC, WEB, PPC, MISC, OSINT, REVERSE, PWN, NETWORK.
  • Каждый таск = «проблема → данные → инструмент категории → флаг».
  • Основной навык: определить категорию и применить нужный инструмент.

    • Почему Python — главный инструмент

  • НТО предметный тур — на Python.
  • ВсОШ: декодирование, анализ файлов — на Python.
  • CTF-категория PPC («программирование») — тоже Python.
  • Тренируем Python каждое занятие — база для 3 олимпиад сразу.

    • Блок А. Теория: ввод-вывод

    Как читает и пишет программа:

    a, b = map(int, input().split())   # читаем несколько int
name = input().strip()             # строка, убираем пробелы
print(f"Привет, {name}")           # форматная строка
print(a + b, a * b)                # несколько значений через пробел

    Механика:

  • input() возвращает строку — даже если на входе цифры.
  • map(int, ...) применяет int() к каждому элементу строки/списка.
  • .split() делит строку по пробелам на список.
  • .strip() убирает лишние пробелы/переводы по краям.

    • Блок А. Теория: зачем приводить типы

  • «2» + «3» в строках = «23» (склейка), а не 5.
  • Поэтому до арифметики обязательно int()/float().
  • Эта ошибка — самая частая на старте и на олимпиаде.

    • Блок Б. Теория: арифметика `//` `/` `%` `**`

    print(9 // 2)   # 4  — целочисленное деление
print(9 / 2)    # 4.5 — обычное деление
print(9 % 2)    # 1  — остаток
print(2 ** 10)  # 1024 — степень
  • // и % — «пара»: деление и остаток от двух целых.
  • Они порождают тарны (десятичные цифры), делимость, разбиение.
  • ** — степень; в больших задачах может быть переполнение.

    • Блок В. Теория: условия

    if n % 2 == 0:
    print("even")
elif n < 0:
    print("negative")
else:
    print("odd")
  • if/elif/else — ветвление по условию.
  • Сравнения: ==, !=, <, >, <=, >=. Логика: and, or, not.

    • Блок Г. Теория: циклы

    for i in range(n):        # 0..n-1
    print(i)
while n > 0:              # пока условие истинно
    n //= 10
  • range(a, b) — числа от a до b−1.
  • for — когда известно число повторов; while — пока верно условие.
  • Аккуратно с while: без изменения переменной — вечный цикл.

    • Циклы — основа перебора

  • Олимпиадные задачи почти всегда = «перебрать варианты циклом».
  • Умение писать циклы = умение решать большинство задач НТО Этап I.

    • ПРАКТИКА 3. Циклы

  • Вывести числа от 1 до n.
  • Таблица умножения для числа n (первые 10 строк).
  • Сумма чисел от 1 до n.

    • Разбор образца из НТО: «Три квадрата»

    Условие: прямоугольник a×b разбить на 3 квадрата, найти их площади.

    Шаги решения:

  • Если a>b — повернуть.
  • Первый квадрат = a×a.
  • Остаток a·(b−a) делим на 2 равных квадрата.
    • a, b = map(int, input().split())
if a > b:
    a, b = b, a
s1 = a*a
s2 = (a*b - s1)//2
print(s1, s2, s2)
    Проверка: (2,2)→ 4, 0, 0? Нет — (2,2) даёт квадрат 2×2 и 2 пустых. Прогони (3,3) и (6,4) сам.

    РАЗБОР ФЛАГА. «Три квадрата» — тесты

    def cut(a, b):
    if a > b: a, b = b, a
    s1 = a*a
    s2 = (a*b - s1)//2
    return (s1, s2, s2)

# проверь: cut(3,3) и cut(6,4) -> что вернёт?
    Ответ

    cut(3,3) → (9, 0, 0); cut(6,4) → (16, 4, 4).

    Важно: значения целые — если остаток нечётный, считай внимательно.

    Типовые ошибки новичка

  • Забывают int() — сумма превращается в «склейку» строк.
  • Путают // и /.
  • Забывают .strip()/.split() при сложном вводе.
  • Округляют вместо целочисленного деления в задачах «на целое».

    • РАЗБОР ФЛАГА. Разбираем ошибку «склейки строк»

    a = input()      # "2"
b = input()      # "3"
print(a + b)     # "23"  — строки склеились!
# Правильно:
a = int(input())
b = int(input())
print(a + b)     # 5
    Правило: всегда приводить ввод к нужному типу до арифметики.
