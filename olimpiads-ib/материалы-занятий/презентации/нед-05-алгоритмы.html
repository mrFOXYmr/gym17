    а «выбрать способ перебора/построения/жадности» — это и есть основа Этапа I НТО.

    Теория. Зачем алгоритмические приёмы

  • Задача ≠ «просто написать Питон»: нужно придумать, как решать.
  • Три базовых приёма покрывают большинство задач предметного тура.
  • Умение выбрать приём важнее знания синтаксиса.

    • Приём 1. Перебор (основа)

    Проверить все варианты и выбрать нужный.

    n = int(input())
for d in range(1, n+1):
    if n % d == 0:
        print(d)
  • Оптимизация: в цикле до √n, пара делителей d и n//d.

    • Перебор до √n (зачем)

    import math
n = int(input())
for d in range(1, int(math.isqrt(n)) + 1):
    if n % d == 0:
        print(d, n // d)
  • Количество итераций падает с n до √n — для n=10⁸ это 10000 шагов вместо 10⁸.

    • Приём 2. Конструктивное построение (НТО «Пробежка»)

    Строим маршрут/последовательность под условие. Вход k кратен 100.

    k = int(input())
m = k // 100
print("ABABA" * (m // 5) + "ABABA"[:m % 5])
  • Идея: найти повторяющийся «паттерн» корректного маршрута.

    • Приём 3. Жадность

    Берём локально оптимальный шаг; работает там, где доказано.

  • Пример НТО «Оптимизация числа»: обмен соседних цифр за |a−b|.
  • Идея: двигать большие цифры влево, но стоимость зависит от разницы цифр.

    • Когда жадность верна, а когда нет

  • Верна: локальный выбор никогда не вредит (мат. доказательство).
  • Не верна: нужен взгляд на несколько шагов вперёд (тогда — перебор/ДП).
  • Пример: «набрать максимальную сумму, не беря соседние» — жадный ломается.

    • ПРАКТИКА А. Перебор

  • Все делители числа n.
  • Сумма делителей.
  • Проверка простоты (делители до √n).
  • Наименьший делитель > 1 составного числа.

    • ПРАКТИКА Б. Конструктивное построение

  • Вывести последовательность: чередуются числа и буквы.
  • «Ёлочка» из символов (вложенные циклы).
  • Строка из повторяющегося паттерна длины m («Пробежка»).
  • Решить НТО «Пробежка» на тестах из условия.

    • ПРАКТИКА В. Жадность и оптимизация

  • Дано число — за минимальное число шагов получить такое-то (жадно).
  • НТО «Оптимизация числа»: 4519 → 9541, посчитать |a−b| по шагам.
  • Сравнить жадный vs полный перебор: когда жадный верен.

    • РАЗБОР ФЛАГА. Перебор делителей с оптимизацией

    Задача: «сумма делителей числа 2026».

    import math
n = 2026
s = 0
for d in range(1, int(math.isqrt(n)) + 1):
    if n % d == 0:
        s += d
        if d != n // d:
            s += n // d
print(s)
    Ответ

    Делители 2026 = 1, 2, 1013, 2026. Сумма = 3042.

    Флаг-формат: N{<сумма-делителей>} → N{3042}.

    Мини-турнир (на время)

    Подсчёт как на олимпиаде: частичные баллы за прохождение тестов.

    Теория. Оценка сложности по-простому

  • O-нотация говорит, как быстро растёт время от размера входа.
  • O(1) — константа; O(n) — линейно; O(n²) — квадратично; O(log n) — логарифмически.
  • 10⁶ операций ≈ мгновенно; 10⁸ — уже долго.
  • Если задача требует «быстро на больших n», перебор до n не подойдёт — нужен до √n.

    • Оценка сложности (метрики)

  • O(n) — цикл по n; O(n²) — вложенные циклы; O(log n) — деление пополам.
  • Перебор делителей до √n лучше, чем до n — во столько, сколько √n/n сокращает шаги.

    • Что уносим

  • 3 приёма (перебор, построение, жадность) + когда что.
  • Понимание сложности O() и оптимизации до √n.
  • Каждый знает свой результат по турниру — заметен рост к НТО.

    • Резюме: что уносим

  • Перебор, построение, жадность — и когда каждый приём уместен.
  • Сложность O(): почему перебор до √n быстрее, чем до n.
  • Схема решения: понять условие → выбрать приём → написать код → проверить.
  • Свой результат на турнире — точка отсчёта к НТО.
