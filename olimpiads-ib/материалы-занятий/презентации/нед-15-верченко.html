    Теория. Специфика письменной олимпиады

  • Ответ — обоснованный вывод, а не только число.
  • Таблицы и матрицы читаются внимательно (знаки +/−).
  • Точность подсчёта важнее скорости.
  • Приёмы те же: перебор, жадность, аккуратные суммы.

    • Тема 15.1. Формат Верченко

  • Заочный отбор + финал.
  • Письменные задачи, часто с таблицами и подсчётами.
  • Внимание к аккуратности вычислений.

    • Тема 15.2. Задачи отборочного этапа (11 класс)

  • Анализ безопасности сети — таблица влияния компонентов защиты.
  • Оптимизация системы — очередь задач по приоритетам/ресурсам.
  • Контрольная сумма — проверка целостности.
  • Код от сейфа — логическая/алгоритмическая.
  • Решётка Кардано — криптографическая маска.

    • Разобрать весь список из условия архива.

    Тема 15.3. Разбор «Анализа безопасности сети»

    Дана матрица влияний компонентов (FW, AVS, IDS, SIEM, WAF, VPN) со знаками +/–.

    Ищем подмножество с максимальной суммой влияний (пример: FW+WAF+VPN → 23).

    Приём: перебор/жадность, аккуратные суммы со знаками.

    Анализ сети: мини-пример

           FW  AVS  IDS  WAF
FW     _   +2   +1   -1
AVS    _   _    +3   +2
IDS    _   _    _    -2
WAF    _   _    _    _

    Подсчёт для {FW,AVS,IDS}: +2+1+3=6 — максимум.

    Перебор всех подмножеств → берём лучшую сумму со знаками.

    ПРАКТИКА А. Анализ безопасности сети

  • Переписать таблицу из условия.
  • Посчитать суммы возможных наборов.
  • Найти максимум.
  • Оформить ответ как в Верченко (компоненты + сумма).

    • Тема 15.4. Оптимизация системы

    Очередь задач: приоритет + доступные ресурсы + порядок выбора.

  • Сформулировать правило выбора.
  • Прорешать тест из условия.
  • Важно: взятие задачи занимает ресурсы.

    • Оптимизация: ключевая идея

  • Целевая функция = сумма приоритетов взятых задач.
  • Ограничение = доступные ресурсы.
  • Жадный порядок: по приоритету/единицу ресурса.
  • Сравнить с наивной сортировкой только по приоритету.

    • ПРАКТИКА Б. Оптимизация

  • Описать алгоритм выбора следующей задачи.
  • Прорешать задачу из условия по шагам.
  • Сравнить с сортировкой по приоритету.

    • Тема 15.5. Контрольная сумма (закрепление)

  • Целостность = контрольная сумма/хеш.
  • Поменялся байт → изменилась сумма → целостность нарушена.
  • Задача дорешивается точно и аккуратно.

    • РАЗБОР ФЛАГА. Максимум по матрице

    По мини-примеру выше — какое подмножество даёт максимум?

    pairs = {("FW","AVS"):2, ("FW","IDS"):1, ("FW","WAF"):-1,
         ("AVS","IDS"):3, ("AVS","WAF"):2, ("IDS","WAF"):-2}
# перебери подмножества и найди лучшую сумму
    Ответ

    Максимум на {FW,AVS,IDS} = 2+1+3 = 6.

    Флаг-формат: VER{<сумма>} → VER{6}.
