    • Секция 1. НТО-стиль Python

    Задачи образца Этапа I:

  • сумма цифр числа;
  • максимум из трёх без max();
  • НОД двух чисел;
  • перебор делителей.

    • Оценка: баллы за прохождение тестов (как на олимпиаде).

    Секция 1b. Примеры из НТО (перебор)

    import math
n = int(input())
cnt = 0
for d in range(1, int(math.isqrt(n)) + 1):
    if n % d == 0:
        cnt += 1
        if d != n // d:
            cnt += 1
print(cnt)   # сколько делителей у 36?
    Ответ

    У 36 делители: 1,2,3,4,6,9,12,18,36 → 9.

    Флаг-пример: FINAL{<количество-делителей>} → FINAL{9}.

    Секция 2. ВсОШ теория + декодирование

  • Вопросы: порты, ~, SHA-256, CSP, iptables.
  • Практика: раскрутить Base64→Base32, hex→текст.

    • Ответы — строго в vsosh{...}.

    Секция 2b. Декодирование цепочки

    import base64
v = "INKEM==="       # Base32
print(base64.b32decode(v))   # какое слово?
    Ответ

    base64.b32decode("INKEM===") → b'CTF'. Флаг-пример: vsosh{CTF}.
