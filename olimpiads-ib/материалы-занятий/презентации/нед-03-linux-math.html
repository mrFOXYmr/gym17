    Права файлов: как считать chmod

  • r=4, w=2, x=1 → сумма: 7=rwx, 6=rw-, 5=r-x, 4=r--, 0=---.
  • chmod 600 = владелец rw-, остальные ничего.
  • chmod 755 = владелец rwx, остальные r-x.
  • Права пишут по 3 группам: владелец / группа / остальные.

    • Соответствие «число → права» (шпаргалка)

    ЧислоБинарноПрава
    7111rwx
    6110rw-
    5101r-x
    4100r--
    0000---

    Теория. chmod — это три бита

  • Каждое право — бит: read=4 (100), write=2 (010), execute=1 (001).
  • Число = сумма включённых битов: 7=4+2+1 (все три).
  • Три цифры = три группы: владелец / группа / остальные.
  • chmod 640 = владелец rw-, группа r--, остальные ---.

    • Теория. Как читать iptables-правило

    iptables -A INPUT -p tcp --dport 443 -j ACCEPT
        |
        |   цепочка    протокол  порт назначения   действие
  • -A INPUT — добавить правило к входящим пакетам.
  • -p — протокол (tcp/udp), --dport/--sport — порт назначения/источника.
  • -j — действие (ACCEPT/DROP).
  • Порядок правил важен: первое совпавшее применяется.

    • Теория. Делимость — через остатки

  • x % 2 — чётность; x % 10 — последняя цифра; x // 10 — отбросить последнюю.
  • «Високосный»: год кратен 400, или (кратен 4 и не кратен 100).
  • Проверка «n делится на m» = n % m == 0.

    • Вопросы ВсОШ в тему

  • «Символ домашней директории» → ~.
  • «Составь правило iptables, запрещающее входящий DNS-трафик от любого источника» → iptables -A INPUT -p udp --dport 53 -j DROP.
  • Как отличить --dport (назначение) и --sport (источник): читаем в сторону пакета.

    • Тема 3.2. Математика в Python (для задач НТО)

    import math
a, b = map(int, input().split())
print(a + b, a - b, a * b, a // b, a % b)
print("НОД:", math.gcd(a, b))
print("НОК:", a * b // math.gcd(a, b))
  • // — целочисленное деление; % — остаток; math.gcd — НОД.
  • НОК = a*b//НОД (формула).

    • Алгоритм Евклида (сколько будет платой)

    def gcd(a, b):
    while b:
        a, b = b, a % b
    return a
  • Работает за O(log min(a,b)) — быстро на больших числах.

    • ПРАКТИКА А. Делимость и остатки

  • Сумма цифр числа (%10 + //10 в цикле).
  • Проверка: делится ли n на m.
  • Количество чётных чисел от 1 до n.
  • «Високосный год» через %4, %100, %400.

    • ПРАКТИКА Б. НОД и НОК

  • НОД через math.gcd и вручную (Евклид).
  • НОК двух чисел формулой.
  • Сокращение дроби a/b (поделить на НОД).
  • «Три квадрата» снова — акцент на // и %.

    • ПРАКТИКА В. Linux-симуляция

  • Команда для просмотра файла passwd.
  • Права, которые даст chmod 640.
  • Что делает iptables -A INPUT -p tcp --dport 22 -j DROP (запрет SSH).
  • Собрать «цепочку»: cd → ls → cat → grep "flag" (как ищут флаг).

    • РАЗБОР ФЛАГА. Правильная сумма цифр

    Ошибка новичка: берут последнюю цифру, но забывают сдвиг.

    n = int(input())
total = 0
while n > 0:
    total += n % 10
    n //= 10          # без этой строки — вечный цикл
print(total)          # считай для 2026
    Ответ

    Для 2026: 2+0+2+6 = 10. Флаг-формат: NT{<сумма-цифр>} → NT{10}.

    Типовые ошибки

  • Путают // (цел.) и % (остаток).
  • Забывают import math перед math.gcd.
  • В chmod путают порядок (7=rwx пишут наоборот).
  • В iptables путают --dport и --sport.
  • В цикле суммы цифр забывают n //= 10 — вечный цикл.

    • Что уносим

  • Навигация и просмотр файлов; пересчёт chmod.
  • Математика: //, %, НОД/НОК; Евклид.
  • iptables: --dport/--sport, -A INPUT.

    • Резюме: что уносим

  • Linux: навигация, просмотр, поиск; принцип «одна утилита — одно дело».
  • chmod = три бита × три группы; пересчёт числа↔прав.
  • iptables: цепочка/протокол/порт/действие.
  • Математика Python: делимость через %, НОД/НОК, Евклид.
