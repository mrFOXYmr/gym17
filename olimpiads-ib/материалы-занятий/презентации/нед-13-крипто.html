    Теория. Три «опоры» крипто-таска

  • Целостность — контрольная сумма/хеш: не изменилось ли.
  • Шифрование — обратимое преобразование данных.
  • Вскрытие — найти ключ или прочитать без него (перебор, частоты).

    • Тема 13.1. Цели защиты данных (CIA)

  • Конфиденциальность — шифрование скрывает содержимое.
  • Целостность — контрольные суммы/хеши фиксируют изменение.
  • Доступность — сервис доступен по требованию.
  • Каждая мера закрывает свою цель ИБ.

    • Тема 13.2. Контрольные суммы

  • Проверка целостности: изменилось ли сообщение/файл.
  • Простейшая — XOR всех байт; надёжнее — хеши (SHA-256).
    • b = b'NTO'
c = 0
for x in b:
    c ^= x
print(c)

    Задача Верченко «Контрольная сумма» — проверить изменение и посчитать.

    Тема 13.3. XOR-шифрование (база CTF-CRYPTO)

    Свойство: a XOR b XOR b == a → повторное применение расшифровывает.

    def xor(data, key):
    return bytes(a ^ b for a, b in zip(data, key * len(data)))

    XOR с односимвольным ключом (перебор)

  • Если шифр одним символом — всего 256 ключей.
  • Перебор по 0..255 и поиск читаемого ASCII.
    • ct = bytes.fromhex("07141c11751b1a02")
for k in range(256):
    d = bytes(c ^ k for c in ct)
    if d.isascii() and all(32 <= x < 127 for x in d):
        print(k, d)   # найди читаемую фразу
    Ответ

    Ключ k=0x55 даёт RAID NOW.

    Формат-флаг: CRYPTO{<фраза>} → CRYPTO{RAID_NOW}.

    • Тема 13.4. Частотный анализ

  • Определение языка/шифра по частотам букв.
  • Помогает вскрывать подстановки и Цезаря.
    • from collections import Counter
freq = Counter(text.lower())
print(freq.most_common(5))
  • Чем длиннее текст, тем надёжнее результат.

    • Теория. Тест на наличие уязвимости (не только вскрытие)

  • XOR односимвольным ключом: 256 вариантов → перебор тривиален.
  • Многосимвольный ключ ломается частотным анализом/подсчётом совпадений.
  • Частоты букв русского языка выше для гласных (о, е, а) — ориентир.
  • Длинный текст даёт надёжную карту частот; короткий — ненадёжен.

    • Тема 13.5. Шифр простой перестановки (до автомата)

  • Блоки, правило-перестановка. Решаем несколько слов быстро.
  • ВсОШ даёт такие в 5-6; встречаются и выше.

    • Тема 13.6. Решётка Кардано (Верченко)

  • Маска с прорезями, 4 поворота на 90°.
  • Наложение → чтение → поворот → ... → текст.
  • Аккуратность поворота = главное. Дорешать пример из архива.
