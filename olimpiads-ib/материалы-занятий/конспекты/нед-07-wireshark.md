## Теория. Что такое hex и зачем
- Один байт = 2 шестнадцатеричные цифры (0–9, a–f).
- Любой файл — это последовательность байтов.
- `45 00 00...` — байты IP-пакета; `48 65 6c` — "Hel".
- hex позволяет увидеть «сырые» данные, которые не видны как текст.

## Тема 7.1. Форматы данных и hex
- `.diff` — файл различий/патч; в ВсОШ хранит закодированное послание.
- hex-представление: каждый байт = 2 hex-символа.
```python
print(bytes.fromhex('4e544f').decode())  # hex -> «NTO»
print('NTO'.encode().hex())              # «NTO» -> hex
```

## Сигнатуры файлов (магические байты)
| Тип | Первые байты |
|-----|--------------|
| PDF | `%PDF` |
| PNG | `\x89PNG` |
| ELF | `\x7fELF` |
| ZIP | `PK\x03\x04` |
| JPEG | `\xff\xd8\xff` |
- По первым байтам определяем тип — это начало любого FORENSIC.

## Тема 7.3. Wireshark и `.pcap`
Задание ВсОШ «Сетевая аномалия» (`traffic_*.pcap`): найти атаку по записи.
Алгоритм:
1. Открыть `.pcap` (File → Open).
2. Применить фильтры `http`, `dns`, `mysql`.
3. Искать подозрительные параметры: `' or '1'='1`, `; ls`, `sleep(`.
4. Определить тип: SQL/LDAP/Command injection.

## ПРАКТИКА В. Просмотр трафика
1. Фильтр `http` — сколько запросов?
2. Follow → TCP Stream: найти параметры запроса.
3. Найти аномалию: подозрительную строку в параметрах.
4. Сформулировать тип атаки (SQLi / LDAPi / Command/...).

## Признаки типов атак (для определения по трафику)
- **SQL injection**: `' or '1'='1`, `--`, `union select`.
- **LDAP injection**: `*)(&(`, `(|(uid=*`.
- **Command injection**: `; ls`, `; id`, `$(cat /etc/passwd)`, `sleep 5`.
- **XSS**: `<script>`, `alert(1)`.

## Теория. Механика типов инъекций
- **SQLi**: внедряют SQL в параметр → меняют запрос (обход логина, чтение БД).
- **LDAPi**: ломают фильтр каталога (`*`/`|(`-синтаксис) → доступ к записям.
- **Command injection**: вставляют команду ОС (`; ls`) → выполнение команд.
- **XSS**: вставляют JS → он исполняется в браузере жертвы.
- Отличие в синтаксисе параметра — главный ключ к определению по трафику.

## Практика В2. Определи атаку по признаку
1. `?user=' or '1'='1' --` → SQLi.
2. `?file=;cat flag.txt` → Command injection.
3. `<script>alert(1)</script>` → XSS.
4. `*)(uid=*)(|(uid=*` → LDAPi.

## Разбор из архива ВсОШ («Сетевая аномалия»)
Типичный шаг: найти пакет с параметром-инъекцией и доказать тип атаки.
```bash
# найти HTTP-параметры с подозрительным содержимым
tshark -r traffic.pcap -Y "http.request" -T fields -e http.request.uri | grep -E "union|sleep|or 1=1"
```
> Разбор: доказываем тип атаки строкой-признаком, а не просто «тип».
