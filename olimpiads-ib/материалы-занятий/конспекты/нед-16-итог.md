## Секция 1b. Примеры из НТО (перебор)
```python
import math
n = int(input())
cnt = 0
for d in range(1, int(math.isqrt(n)) + 1):
    if n % d == 0:
        cnt += 1
        if d != n // d:
            cnt += 1
print(cnt)   # сколько делителей у 36?
```
::: Ответ
У 36 делители: 1,2,3,4,6,9,12,18,36 → **9**.
Флаг-пример: `FINAL{<количество-делителей>}` → `FINAL{9}`.
:::

## Секция 2b. Декодирование цепочки
```python
import base64
v = "INKEM==="       # Base32
print(base64.b32decode(v))   # какое слово?
```
::: Ответ
`base64.b32decode("INKEM===")` → `b'CTF'`. Флаг-пример: `vsosh{CTF}`.
:::
