## Теория. Зачем разведка первым делом
- Нельзя эксплуатировать то, чего не видишь.
- Разведка = «карта местности»: открытые порты, версии, сервисы.
- Каждый открытый порт — потенциальный вектор входа.
- Версия сервиса подсказывает конкретную уязвимость.

## Зачем nmap
- Первый шаг любой атаки/аудита — разведка: какие порты и сервисы открыты.
- В Innopolis тур2 и НТО командном это обязательно оценивается.
- Учим работать безопасно и только на учебных машинах.

## Тема 9.1. Ключевые команды nmap
```bash
nmap -sV -p- <ip>     # все порты + версии
nmap -sC -sV <ip>     # дефолтные скрипты + версии
nmap -p 80,3306,3000 <ip>
nmap -oN out.txt <ip> # сохранение результата
nmap -Pn <ip>         # не делать хостовую разведку
```
Флаги: `-sV` версии, `-p-` все порты, `-sC` дефолтные скрипты, `-oN` вывод в файл.

## Что означают флаги (разбор)
- `-sV` — определить версии сервисов.
- `-sC` — дефолтные скрипты (безопасные проверки).
- `-p-` — все 65535 портов.
- `-oN out.txt` — сохранить в читаемый файл (для отчёта).
- `-Pn` — не пингуя, сразу сканировать порты.

## Теория. Как читать вывод
```
PORT     STATE  SERVICE  VERSION
22/tcp   open   ssh      OpenSSH 8.2
80/tcp   open   http     nginx 1.18
3000/tcp open   http     Node.js/Express
3306/tcp open   mysql    MySQL 8.0
```
- Порт и состояние; сервис и **версия**.
- Версия — ключ: по ней ищут конкретную уязвимость.
- Веб-порты часто 80 и 3000 (Node) — оба надо проверить.
- БД (3306) — отдельный вектор добычи данных.

## Тема 9.2. Как читать результат сканирования
- 80/3000 → web (зайти, посмотреть, `/robots.txt`, каталоги).
- 3306 → MySQL (подключиться, посмотреть БД).
- 22 → SSH (слабые/дефолтные доступы; никогда — грубые атаки без разрешения).
- 5432 → PostgreSQL (частый источник данных в CTF).

## Карта «порт → следующий шаг»
| Порт | Сервис | Что дальше |
|------|--------|-----------|
| 80/3000/8080 | web | /robots.txt, исходники, каталоги |
| 3306 | MySQL | подключение, БД, креды |
| 5432 | PostgreSQL | подключение, БД |
| 22 | SSH | доступ, ключи/слабый пароль |
| 6379 | Redis | часто без аутентификации |

Вопрос НТО: на каком порту самое вероятное веб-приложение и почему?
::: Ответ
80 и 3000 — оба web; сначала проверить оба, потом смотреть на порт БД.
Если это dev-Node — вероятное веб-приложение на **3000**.
Формат-ответ: `NMAP{<порт>}` → `NMAP{3000}`.
:::

## Этика и безопасность
- Сканировать только согласованные учебные среды.
- Никаких грубых атак/брутфорса на реальные системы.
- Олимпиадная подготовка: действуем легально и корректно.

## Типовые ошибки
- Сканируют без `-p-` и пропускают порты.
- Путают `-sV` и `-sC`.
- Не записывают результат (теряют данные для отчёта).
- Атакуют реальные машины — запрещено.
