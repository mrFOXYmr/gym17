## Теория. Структура таска = «данные → категория → инструмент → флаг»
- Таск даёт: описание, файл/сервис/текст.
- Определяем категорию по виду данных.
- Применяем инструмент категории.
- Получаем флаг и проверяем формат.
- Ошибка в определении категории = применение не того инструмента.

## Что такое CTF
- Capture The Flag — соревнование, где за решение таска получают «флаг».
- Флаг = скомпрометированные данные, пароль, строка-ответ.
- Innopolis отбор проходит в формате CTF task-based.

## Тема 12.1. Категории CTF
| Категория | Что это |
|-----------|---------|
| NETWORK | сетевые протоколы, анализ трафика |
| PPC | программирование/автоматизация |
| MISC | логика, нестандартное мышление |
| PWN | уязвимости в скомпилированных приложениях |
| CRYPTO | шифры, кодирование |
| FORENSIC | анализ файлов/памяти/метаданных |
| WEB | уязвимости веб-приложений |
| OSINT | поиск по открытым источникам |
| REVERSE | реверс исполняемых файлов |

## Тема 12.2. Категории под микроскопом
- CRYPTO: openssl, xxd, base64/32.
- FORENSIC: file, strings, binwalk, EXIF.
- WEB: gobuster, burp, sqlmap (осторожно).
- OSINT: поиск, метаданные, соцсети.

import base64

> Разбор: распознать категорию (CRYPTO/MISC) → применить простой инструмент → флаг.

## РАЗБОР ФЛАГА. Мини-цепочка «категории»
Строка `JNCVS===` (Base32, категория CRYPTO):
```python
import base64
print(base64.b32decode("JNCVS==="))   # что получится?
```
::: Ответ
`base64.b32decode("JNCVS===")` → `b'KEY'`.
Флаг-формат: `CTF{<слово>}` → `CTF{KEY}`.
:::

## Общий план решения таска
1. Понять категорию/технологию.
2. Собрать данные (файлы, трафик, исходники).
3. Применить инструмент категории.
4. Получить флаг, проверить формат.
5. Автоматизировать повторы (Python).

## Мини-CTF-раунд
5 мини-тасков (по одному на CRYPTO/FORENSIC/WEB/MISC/PPC).
Каждый решает сам/в паре; считаем флаги.
Разбор после — как «раскручивали» таск.

## Типовые ошибки
- Сдают не флаг, а «сырьё» (нужно отобрать ответ в формате).
- В FORENSIC не смотрят `strings`/`binwalk` — пропускают спрятанное.
- В PPC пытаются руками, а не скриптом (потеря времени).
- Не определяют категорию → бьют не тем инструментом.
