## Теория. Зачем шифрование (цели ИБ)
- Конфиденциальность: только адресат читает.
- Целостность: сообщение не изменено.
- Доступность: сервис доступен.
- Классические шифры решают по большей части конфиденциальность.
- В олимпиадах важны и «вскрытие» (найти ключ/ответ), и целостность.

## Тема 4.1. Шифр простой перестановки

## Тема 4.2. Шифр Цезаря
Сдвиг каждого символа на фиксированное число.
```python
def cesar(s, shift):
    out = []
    for ch in s:
        if ch.isalpha():
            base = ord('а')
            out.append(chr((ord(ch) - base + shift) % 32 + base))
        else:
            out.append(ch)
    return ''.join(out)
```
- Модуль `32` даёт «перенос» по алфавиту (без Ё).
- Для латиницы — модуль 26 и `ord('a')`.

## Тема 4.3. Шифр Виженера
- Побуквенное сложение с ключом (ключ повторяется). Надёжнее Цезаря.
- Идея: позиция = (буква + ключ) mod длина алфавита.
```python
def vigenere(text, key):
    out = []
    for i, ch in enumerate(text):
        k = ord(key[i % len(key)]) - ord('a')
        out.append(chr((ord(ch) - ord('a') + k) % 26 + ord('a')))
    return ''.join(out)
```

## Тема 4.4. Решётка Кардано (Верченко)
- Маска с прорезями; накладываем, читаем, поворачиваем на 90°, повторяем (4 раза).
- Аккуратность поворота — главный источник ошибок.
- Порядок: наложил → прочитал прорези → повернул → снова → … 4 раза.

## Тема 4.5. Контрольные суммы и XOR
```python
b = b'NTO'
c = 0
for x in b:
    c ^= x
print(c)
```
- Свойство: `a ^ b ^ b == a` — база многих CTF-шифров.
- XOR-сумма байт = простейшая проверка целостности.

## Теория. Что такое модуль (`%`) и зачем в шифрах
- Алфавит конечен: от `А` до `Я` (32 буквы, без `Ё`).
- Сдвиг «вправо» на конец должен **завернуться** на начало.
- `% 32` делает именно это: (код + сдвиг) делится на 32, остаток — новая позиция.
- Без модуля «З» со сдвигом +3 ушло бы за алфавит; с модулем оно корректно.

## Теория. Как работает XOR (побитово)
- XOR — сравнение двух битов: различаются → 1, совпадают → 0.
- Свойство симметрии: `x ^ k ^ k == x`.
- Поэтому XOR-шифрование с тем же ключом и шифрует, и расшифровывает.
- Контрольная сумма = последовательный XOR всех байт.
