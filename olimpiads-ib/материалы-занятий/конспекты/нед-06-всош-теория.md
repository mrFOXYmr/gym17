## Теория. Зачем кодировать (а не шифровать)
- Base64/32 не защищают, а **представляют** данные в тексте.
- Нужны для передачи/хранения бинарных данных текстом.
- «Раскрутка» = обратная операция, пока текст читаемый.
- В олимпиадах — наоборот: данные закодированы многократно.

## Тема 6.2. Декодирование Base32/Base64
- Base64 кодирует в 64 символа; Base32 — в 32.
- Задача ВсОШ «Полимерный контейнер»: данные закодированы НЕ ОДИН раз.
```python
import base64
s = input().strip()
while True:
    try:
        s = base64.b32decode(s).decode()
    except Exception:
        break
print(s)
```
- «Раскрутка» = повторяем, пока не перестанет декодироваться.

## Разница алфавитов Base64 и Base32
- Base64: `A–Z a–z 0–9 + /` и оконечный `=`.
- Base32: `A–Z 2–7` (без `0`/`1`/`8`/`9`), выравнивание `=` до кратности 8.
- Как понять, что перед тобой B32: только прописные буквы латиницы и цифры 2–7.

## Теория. Как выглядит «раскрутка» на практике
```python
import base64
def unwrap(s):
    while True:
        for fn in (base64.b64decode, base64.b32decode):
            try:
                s = fn(s).decode(); break
            except Exception:
                continue
        else:
            break
    return s
```
- Пробуем каждый алфавит; если падает (bad padding) — пробуем следующий.
- Как только ни один не декодируется — текст чистый, остановились.
- Защита от вечного цикла: try/except и условие выхода.

## ПРАКТИКА А. Раскрутка кодирования
1. Строку закодировать в Base64 → декодировать обратно.
2. Двойное кодирование (Base64+Base64) → раскрутить циклом.
3. Микс: Base64 затем Base32 → раскрутить, пробуя оба.
4. Написать универсальную «раскрутку» с try/except.

## РАЗБОР ФЛАГА. Многослойное кодирование
Строка `VS{...}`-формата: раскручиваем до читаемого.
```python
import base64
s = "S05DVUdWS1NJVlBVR1NLUUpCQ1ZFWFpVR0k9PT09PT0="
print(unwrap(s))   # сколько слоёв? какой результат?
```
::: Ответ
1-й слой: Base64 → `KNCUGVKSIVPUGSKQJBCVEXZUGI======`.
2-й слой: Base32 → `SECURE_CIPHER_42`.
Флаг в формате ВсОШ: `vsosh{SECURE_CIPHER_42}`.
:::
