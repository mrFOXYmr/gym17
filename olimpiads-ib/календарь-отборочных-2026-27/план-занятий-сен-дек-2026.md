## Структура занятия (рекомендация)
- **Каждый урок — 2 часа подряд (без перерыва), 1 раз в неделю + домашка.**
- Теория / лекция по теме: 25–30 мин.
- Практика — разбор реальных задач прошлых лет (из папок): 45–50 мин.
- Самостоятельное решение (формат олимпиады, на время): 35–40 мин.
- Рефлексия / разбор ошибок / анонс домашки: 5–10 мин.
- Домашнее задание: 3–5 задач по теме из архива.

## МЕСЯЦ 1 — СЕНТЯБРЬ. База ИБ + вход в программирование (НТО Этап I)

**Тема месяца:** основы сетей, ОС Linux, криптография-«скретч», базовый Python.
Занятия подчинены НТО Этап I (индивидуальный предметный тур — информатика).

- **Нед. 1** — Введение в олимпиадный трек ИБ. Какие олимпиады, форматы, как
  устроен НТО/ВсОШ/Иннополис/Верченко. Обзор заданий прошлых лет (презентация
  примеров из папок НТО и ВсОШ). Простейшие задачи на Python: ввод/вывод,
  условия, циклы.
- **Нед. 2** — Порты и протоколы (HTTP=80, HTTPS=443, SSH=22, DNS=53, FTP=21).
  Разбор теоретических вопросов ВсОШ ИБ (файл ВсОШ/2025-26/школьный-10-11).
  Python: строки, срезы, работа с символами.
- **Нед. 3** — Основы Linux: файловая система, права, команды (ls, cd, chmod,
  iptables основы). Математика в Python: целочисленные операции, gcd, признаки
  делимости — под НТО "экология"/три квадрата.
- **Нед. 4** — Классическая криптография: шифры перестановки, Цезаря, Виженера,
  решётка Кардано (пример из Верченко). Домашка — код со счётом частот.
  **Контроль:** пробный предметный тур по образцу НТО Этап I (Python).

**Материалы папок:** НТО/{\*,2020-2021}/infbez-отбор-тур1.pdf, ВсОШ школьный 9/10-11.

## МЕСЯЦ 2 — ОКТЯБРЬ. НТО Этап I + ВсОШ школьный (21.10)

**Тема месяца:** алгоритмы и структуры данных под НТО; полный разбор формата
ВсОШ ИБ (теория + декодирование). Кульминация — две реальные олимпиады.

- **Нед. 5** — Алгоритмы: перебор, конструктивное построение, жадность.
  Разбор задач НТО infbez-отбор-тур1 (пробежка, маршруты).
  **Напоминание:** отправить НТО Этап I (идёт 17.09–23.10).
- **Нед. 6** — ВсОШ ИБ: разбор всех категорий (порты, браузерная безопасность —
  CSP, SOP, CORS; SHA-256; iptables). Практика: декодирование Base32/Base64 из
  ВсОШ/2025-26/школьный-9 (полимерный контейнер, пассивный анализ).
- **Нед. 7** — Работа с бинарными/текстовыми файлами, hexdump, формат diff,
  декодирование. Wireshark: чтение .pcap, анализ трафика, поиск аномалий
  (задача "Сетевая аномалия" ВсОШ).
- **Нед. 8 — ВсОШ школьный этап 21.10.2026.** Установочная беседа + лёгкая
  тренировка накануне. После 21.10 — разбор реальных вопросов.
  **Контроль:** пробный школьный этап ВсОШ по прошлогодним материалам.

**Материалы папок:** ВсОШ, НТО.

## МЕСЯЦ 3 — НОЯБРЬ. НТО Этап II (командный) + старт CTF

**Тема месяца:** практическая кибербезопасность — сканирование, уязвимости web,
базовый pentest; старт CTF-категорий под Иннополис.

- **Нед. 9** — Linux для атакующего: nmap (сканирование портов -sV -p-), анализ
  сервисов, mysql/web. По мотивам Иннополис отбор-тур2 (взлом VM). Разбор
  методички Иннополис/2024-25/отбор-тур2.
- **Нед. 10** — Web-уязвимости: LFI, SQL-injection, XSS, обходов. Пример LFI из
  Иннополис (финал тур1). Практика в каталогах/приложениях.
- **Нед. 11 — НТО Этап II (05.11–11.12).** Формат командного кейса, как
  распределять роли в команде (разведка/атака/отчёт). Тренировка на машине из
  архива. **Контроль:** командная мини-игра на взлом и отчёт.
- **Нед. 12** — Введение в CTF: категории CRYPTO, MISC, FORENSIC, OSINT, PPC,
  WEB, PWN, REVERSE (каталог из Иннополис отбор-тур1). Решение простых тасков.

**Материалы папок:** Иннополис (тур1/tур2, финал), НТО командные туры.

## МЕСЯЦ 4 — ДЕКАБРЬ. CTF-направление + подготовка к заочно-отборочным (Иннополис тур1, Верченко)

**Тема месяца:** вокруг CTF и заказных олимпиад с заочной формой (Иннополис
отбор, Верченко отбор). Закрепление всех форматов перед новым годом.

- **Нед. 13** — CRYPTO продвинутый: контрольные суммы, XOR, частотный анализ,
  классические шифры до автоматизма (Верченко: контрольная сумма, решётка
  Кардано). Команды: openssl, base64, xxd.
- **Нед. 14** — FORENSIC + OSINT: анализ файлов, метаданные, поиск флага по
  подсказкам, .diff/.pcap. PPC: автоматизация обработки данных на Python.
- **Нед. 15** — Верченко формат: письменные задачи анализа безопасности сети,
  оптимизации (компоненты защиты) — разбор Верченко/2024-25/11-отбор.
  Итоговый срез по всем 4 олимпиадам — что и когда дальше (Иннополис тур1
  ~конец года, Верченко отбор ~ноябрь–февраль).
- **Нед. 16** — Генеральная репетиция: смешанная подборка заданий всех форматов
  (НТО Python, ВсОШ теор+декод, Иннополис CTF-категории, Верченко письменные).
  План на январь–февраль (муниципальный ВсОШ, Иннополис тур2).
